### Vad jag gjorde

- Skapade resursgruppen `rg-novatrix-v34` i regionen `Sweden Central`.
- Skapade den virtuella servern `vm-novatrix-web`.
- Valde `Ubuntu Server 24.04 LTS Gen2` och storleken `Standard_B2ats_v2`.
- Öppnade port 80 för inkommande HTTP-trafik.
- Laddade ner SSH-nyckeln till den lokala datorn.
- Konfigurerade rättigheter på nyckelfilen i PowerShell.
- Anslöt till servern via SSH med privat nyckel
